Our Privacy Commitment: TrustCue is designed so you can safely evaluate suspicious text, links, and screenshots without exposing personal data. Guest mode is 100% functional. Message text, screenshots, sensitive data redaction, and scam indicator evaluation execute entirely on your device and are never uploaded by default.

1. Information Processed Locally (Never Collected)

The following data elements are processed strictly in-memory or stored within your device's sandboxed storage. They are never transmitted to our servers or third parties:

  • Message Content: Text you enter or paste for local rule evaluation.
  • Screenshots: Images selected for on-device OCR (Latin optical character recognition via bundled Google ML Kit). Images remain in temporary cache memory and are deleted upon text extraction or session close.
  • Sensitive Data Redactions: Phone numbers, email addresses, and codes detected by on-device pattern filters.
  • Local Saved Reports: Reports you choose to save on-device are stored in an app-private SQLite database protected against device backup extraction (android:allowBackup="false").
  • Exported Documents: Text and PDF files generated locally during report export.

2. Optional Registered Account Information

Creating an account is entirely optional. When you choose to register, we collect:

  • Email Address: Used solely for account authentication, password recovery, and login sessions via Supabase GoTrue Auth.
  • Display Name: Optional user nickname stored in your profile. You may update or remove it anytime.
  • Account UUID: A standard identifier assigned to manage sessions and enforce fair-usage daily AI quotas.

3. Optional Consented Cloud AI Analysis

If you explicitly request secondary AI analysis ("Ask Cloud AI"):

  • What is Sent: Only the reviewed, redacted text displayed in your affirmative consent modal is transmitted over encrypted TLS 1.3 to our FastAPI server and forwarded to Groq Inc.
  • Strict Boundary: Original screenshot images, device identifiers, IP addresses, location data, and user profile details are never transmitted to the AI provider.
  • Zero Training Guarantee: Submitted text is never used to train AI models. Groq retains diagnostic API logs for up to 30 days solely for security monitoring and abuse investigation before automated deletion. The TrustCue backend does not store this text in any database.

4. Optional Cloud Report Synchronization

If you explicitly enable cloud synchronization (disabled by default):

  • Only high-level report metadata is synced: client report ID, timestamp, indicator categories (e.g., urgency_or_pressure), and risk assessment.
  • Our database enforces a strict check constraint (chk_report_payload_privacy) actively rejecting any upload containing raw message text, OCR excerpts, evidence quotations, screenshots, or message hashes.
  • You can purge all cloud reports at any time with a single tap in the app.

5. Data Retention & Permanent Deletion

TrustCue provides complete control over your data:

  • In-App Deletion: Tap Account → Delete Account. This permanently deletes your authentication record, user profile, quota history, and synced reports from our servers using an atomic cascade deletion (ON DELETE CASCADE).
  • External Web Request: If you uninstalled the app, submit an account deletion request via our Account Deletion Page or email muhammadtaimoorajmal@gmail.com.

6. Security & Encryption

  • All network transmissions use modern TLS 1.3 encryption.
  • On-device auth tokens are protected using AES-GCM encryption backed by the Android Hardware KeyStore.
  • Hosted database tables are protected by Row Level Security (RLS) and disk encryption (AES-256).
