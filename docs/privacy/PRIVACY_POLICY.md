## 1. Introduction & Core Philosophy
TrustCue is a mobile application developed to assist users in identifying common social engineering patterns, manipulative language, and structural link anomalies in suspicious digital messages. 

We believe that evaluating security threats must never require compromising user privacy. TrustCue is engineered on a **privacy-first, on-device architecture**:
- The application is **100% operational in guest mode** without creating an account or providing any personal information.
- By default, all message intake, text recognition (OCR), sensitive data masking, scam-indicator evaluation, and report history remain strictly within your device's sandboxed local storage.
- Remote processing and cloud synchronization are entirely optional and require explicit, affirmative user consent.

## 2. Information We Collect and How We Use It

### 2.1 Information Processed Locally (Never Collected or Transmitted)
The following information is processed strictly in-memory or stored in your device's app-private SQLite database. It is **never transmitted to our servers or any third party**:
- **Message Content:** Text you paste or type for review.
- **Screenshots:** Images selected from your photo library or camera for on-device optical character recognition (OCR). OCR processing is performed locally using bundled Google ML Kit Latin models. Images are held in temporary cache memory and deleted upon extraction or session dismissal.
- **Sensitive Data Redactions:** Phone numbers, email addresses, and verification codes identified by the on-device scanner. Redactions are applied locally to the text before any further review.
- **On-Device Analysis Findings:** Scam indicator findings, evidence citations, and confidence tiers generated by the local 10-rule heuristic engine.
- **Local Saved Reports:** Reports you choose to save on your device via the "Save on this device" action. These stay in an encrypted app-private SQLite database (`trustcue.db`) protected by Android sandbox isolation (`android:allowBackup="false"`).
- **Exported Documents:** Plain text (`.txt`) and PDF (`.pdf`) files generated when you use the Export feature. These are written to a private temporary cache and automatically pruned after 2 hours.

### 2.2 Optional Registered Account Information (Collected via TLS)
If you choose to create a registered account (which is optional), we collect:
- **Email Address:** Used solely for authentication, session verification, and password recovery via Supabase GoTrue Auth.
- **Display Name (Optional):** A user-chosen nickname stored in your profile. You may leave this blank or change it at any time.
- **Account Identifiers:** A randomly generated UUID assigned by our authentication system.
- **AI Quota Tracking:** Daily request counter (e.g., 15 requests per day) to ensure fair usage of cloud inference infrastructure.

### 2.3 Optional Consented Cloud AI Analysis (Collected in Transit)
When you choose to request a secondary AI analysis ("Ask Cloud AI"):
- **What is Sent:** Only the reviewed, redacted text displayed in your confirmation modal is transmitted over encrypted TLS 1.3 to our FastAPI server and forwarded to our AI infrastructure provider, Groq Inc.
- **What is Excluded:** Original screenshot images, device identifiers, IP addresses, location data, and user profile details are **never** provided to the AI provider.
- **Retention & Usage:** Groq processes the text to evaluate linguistic pretexting cues. Per Groq’s data protection terms, submitted text is **never used to train artificial intelligence models**. Groq retains diagnostic API logs for up to 30 days solely for security monitoring and abuse investigation, after which they are permanently deleted. The TrustCue backend does not store this text in any database.

### 2.4 Optional Cloud Report Synchronization (Collected & Stored)
If you explicitly opt in to cloud synchronization (`sync_enabled = true`):
- **What is Synced:** Metadata only—client report ID, creation timestamp, indicator categories (e.g., `urgency_or_pressure`), and overall risk assessment.
- **Privacy Constraint:** Our database enforces strict architectural check constraints (`chk_report_payload_privacy`) that actively reject any upload containing raw message text, OCR excerpts, evidence quotations, screenshots, or message hashes.
- **Purge Control:** You can purge all cloud reports at any time with a single tap in the app.

## 3. Third-Party Service Providers
TrustCue engages reputable infrastructure providers under strict privacy terms:
1. **Supabase (PostgreSQL & GoTrue Auth):** Hosts user authentication, account profiles, and opt-in report metadata in a secure PostgreSQL database with Row Level Security (RLS) and encryption at rest (AES-256).
2. **Render (FastAPI Application Hosting):** Hosts our stateless backend API under HTTPS/TLS 1.3. Server logs retain operational HTTP status codes and timestamps for system reliability, with query parameters and body payloads stripped.
3. **Groq Inc. (Cloud AI Provider):** Provides high-speed LPU inference for optional, consented AI analysis. Does not use customer data for model training; retains diagnostic logs for up to 30 days before automated deletion.

**We do NOT use:**
- Advertising networks or tracking SDKs.
- Third-party analytics platforms (e.g., Google Analytics, Firebase Analytics, Facebook SDK).
- Background location services or biometric profiling.

## 4. Data Retention and Account Deletion

### 4.1 In-App Deletion
You maintain complete control over your data directly within the TrustCue application:
- **Local Reports:** Delete individual reports from the Saved Reports screen, or clear all local reports and cache via `Privacy & Data -> Clear Local Data`.
- **Cloud Reports:** Purge all synced cloud metadata instantly via `Account -> Purge Cloud Reports`.
- **Permanent Account Deletion:** Tap `Account -> Delete Account`. This initiates an atomic cascade deletion (`ON DELETE CASCADE`) on our servers that immediately and irreversibly deletes your authentication record, user profile, quota history, and synced reports. Your local device session and local reports are also purged.

### 4.2 External Web Deletion Request
In compliance with Google Play's User Data Policy, if you have uninstalled the application or cannot access your device, you may request permanent deletion of your account and all associated cloud data via our public web resource:
- **Web Deletion Portal:** `https://muhammadtaimoorajmal.github.io/trustcue-mobile/privacy/account_deletion.html`
- **Email Deletion Request:** Send an email from your registered account address to `muhammadtaimoorajmal@gmail.com` with the subject line `TrustCue Account Deletion Request`. All associated cloud records will be verified and permanently deleted within 7 business days.

## 5. Security Measures
We implement comprehensive technical and organizational safeguards:
- **TLS 1.3 Encryption:** All network transmissions are strictly encrypted in transit.
- **Hardware KeyStore Protection:** Mobile auth tokens are stored using AES-GCM encryption backed by the Android Hardware KeyStore (`flutter_secure_storage`).
- **No Device Backups (`android:allowBackup="false"`):** App-private SQLite databases and preference files cannot be extracted through unauthorized adb or cloud backups.
- **Row Level Security (RLS):** Database records are partitioned so users can never access or query data belonging to other accounts.
